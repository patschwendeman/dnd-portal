Annahmen
  • QR-Code → /: nur die Charaktere des aktiven Abenteuers, kein Admin-Zugang.
  • Immer die Auswahl, keine Weiterleitung zum letzten Charakter.
  • Mehrere Handys pro Charakter erlaubt.
  • Tippen → /player/:id; Settings-Menü → „Charakter wechseln“ (letzter Eintrag) → zurück zur Auswahl.
  • Settings-Menü liegt immer über allen Elementen.
  • Hintergrundbild des Abenteuers je wirksamem Theme auf Auswahl und Player Screen, Glas-Kacheln wie im Admin.
  • Abenteuerwechsel → zurück zur Auswahl mit Hinweis.
  • Auswahl hoch und quer, „Bitte quer halten“ nur im Player Screen.
  • Theme-Menü (pro Gerät) auf beiden Seiten.
